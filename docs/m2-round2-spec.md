# M2 Round 2 Spec — 香港化（糾正規則 + 口語/書面切換）

## 背景
- M1 + M2 round 1 完成（離線粵語聽寫 + 簡繁轉換 + 刪雲端 + 自動下載 + 係 copula fix）
- Research 發現：SenseVoice **唔支持 hotword**（官方確認：只有 transducer 模型支持 hotword，SenseVoice 非自回歸模型唔支持）
- 所以 brief 原本嘅「hotword 詞典」改為「後處理糾正規則」

## 範圍（2 項）
1. 港式糾正規則表（後處理，fix 固定 ASR 誤認）
2. 口語 ↔ 書面切換（規則表）

---

## 1. 港式糾正規則表

### 目標
SenseVoice 喺 yue mode 下有一啲固定誤認，要喺輸出後用「糾正規則」自動改返啱。

### 做法
- 喺現有「糾正規則」（correction rules）功能基礎上，內建一份默認「港式糾正規則」
- 應用時機：簡繁轉換（OpenCC s2hk + 係 copula rule）**之後**
- 規則 = 常見 SenseVoice 粵語誤認 → 正確字

### 已知誤認（要 cover）

**安全替換**（高置信度，可直接替換）：
- 「知家」→「即刻」
- 「試下」→「試吓」（口語寫法）
- 「啦」→「喇」（語氣詞，粵語口語標準寫法）

**要小心**（要 context 判斷，唔可以盲目替換）：
- 「穩」→「搵」：只有「搵」聽錯做「穩」嘅情況先替換，但「穩定」「穩陣」「穩妥」「穩步」嘅「穩」係啱，**唔可以改**
  - 判斷方法：如果「穩」後面跟「定／陣／妥／步／健」等字，保留「穩」；否則「穩」單獨成詞（例如「去穩嘢」）可能係「搵」
  - 如果呢個 rule 太難可靠實現，可以先 skip，留返用戶手動加規則

### 可編輯
- 規則表要可編輯（用戶可以加／刪自訂規則）
- OpenLess 已有「糾正規則」編輯 UI，確認內建規則同用戶規則一齊生效

## 2. 口語 ↔ 書面切換

### 目標
用戶可以切換輸出模式：
- **口語模式（默認）**：直接出口語粵字（而家嘅嘢）
- **書面模式**：口語 → 書面語（正式書面中文，適合 email）

### 做法
- **規則表實現**（唔依賴雲端 LLM）
- 切換：設定度加一個「輸出模式」選項（口語 / 書面），默認口語
- 書面模式嘅轉換規則（口語字 → 書面字），應用喺簡繁轉換 + 係 rule 之後：
  - 唔→不、嘅→的、係→是、喺→在、嚟→來、返→回、畀→給、攞→拿、睇→看、講→說、食→吃、飲→喝、瞓→睡、冇→沒有、而家→現在、點解→為什麼、咁樣→這樣
  - 「咁」→「這樣／那麼」（要 context）
  - 「啲」→「些／一點」（要 context）

### 已知 limitation（可接受）
- 規則表只做「字詞替換」，唔做「語序調整」
- 例：「我食先」會出「我吃先」（唔係「我先吃」）—— 呢個係可接受 limitation（brief 講用規則表）
- 書面模式輸出係「書面字詞 + 粵語語序」，唔係完美書面中文
- 書面模式係 optional（默認口語），用戶唔想書面化就唔揀

### 切換 UX
- 設定度切換（最簡單），之後可以加 hotkey 即時切換
- 書面模式唔影響口語模式（默認口語）

---

## 驗收標準
1. 糾正規則：講「我而家就即刻試」，輸出應該係「即刻」唔係「知家」
2. 口語/書面切換：講「我今日唔去觀塘喇」
   - 口語 mode：出「我今日唔去觀塘喇」
   - 書面 mode：出「我今天不去觀塘了」（字詞替換，語序可以唔完美）

## 非目標
- 唔做完美書面中文（語序調整）—— 規則表做唔到，唔依賴雲端 LLM
- 唔做 hotword（SenseVoice 唔支持）
- 唔加其他新功能
